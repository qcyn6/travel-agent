# 全国热门城市景点首轮核查台账

> 任务目标：基于现有景点库，按省级行政区逐一检查热门地级市/地区的代表性景点；仅补充能核实名称、简介和公开地图实体坐标的真实独立景点。不得为凑数量录入，不使用高德 API/MCP 或消耗高德额度，不新增景点表字段。每次写库后同步对应省份向量并更新统计。
>
> 城市口径：只按数据库现有省级城市/地区归属处理，不继续拆县建立目标清单；旅游点位可以位于该地级市所辖区县。对同名别名、已收录组合景区内子点、无法确认同城坐标或资料不足的候选，记录跳过，不新增。
