# 全国热门城市景点第二轮核查台账

> 目标：在34个省级地区已完成首轮热门城市核查的基础上，继续优先补充景点数量偏少的热门城市。简介以政府、场馆等权威来源为准；坐标使用可追溯的公开具名地图 POI（OSM、百度地图等），并记录原始坐标系与来源链接。所有条目须与库内景点不重复、不属于已收录组合景区子点。不调用高德服务、不新增景点表字段；百度 BD-09 坐标在本地转换为项目使用的 GCJ-02 后写入；写库后同步向量并刷新统计。
