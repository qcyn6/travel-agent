`个性化旅游规划系统_MVP详细开发步骤_V2.md` 的实际实现状态。

## 前端对话式演示

- 已增加 Vue 3 + TypeScript + Vite 前端。
- 已实现自然对话、实时需求卡、可编辑确认单、SSE 规划进度和最终逐日行程页面。
- 已增加 MySQL `conversations`、`conversation_messages` 表，支持当前匿名会话内的多轮记忆。
- 同一标签页使用 `sessionStorage` 恢复当前会话和已生成方案。

## 数据边界

- MySQL 保存省份、城市、查询过的高德 POI 和已经生成的景点知识。
- Chroma 只按需保存已完成知识的向量，不预构建全国景点库。
- Redis 按文档暂不接入 MVP。
- `failed` 知识不会被普通规划请求反复重试；可通过单景点强制刷新接口显式重试。
- MVP 不实现跨省多城市、Evaluator、Replanner、复杂预算、复杂天气和城市间精确交通优化。
