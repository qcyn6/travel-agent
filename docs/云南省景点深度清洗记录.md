## 清洗范围与约束

- 数据范围：云南省景点表；首轮 335 条，公开核验及 demo 清理后删除 6 条，当前保留 329 条。
- 数据来源：当前 MySQL 景点表、项目已有公开资料快照、本地知识清单，以及政府、景区官网、文旅部门、科研机构和世界遗产公开页面。
- 外部服务约束：全程未调用高德 API、地图 POI API 或地理编码服务，没有消耗高德额度。
- 表结构约束：只更新现有 `category`、`tags`、`description`、`visit_duration_minutes` 四个字段，没有新增字段，也没有改写经纬度。

### 删除依据

删除不是依据名称主观判断，而是先检查省份、POI、名称和坐标，再对多个公开来源进行检索：

1. `街心花园`：只有泛化的城市公共空间/地图式结果，没有稳定的景点级简介或主管部门资料。
2. `抚仙湖公园`：抚仙湖、月亮湾、明星渔洞和红沙滩均有明确公开资料，但这个精确名称没有足够可靠的独立景点资料，疑似泛化别名。
3. `兰坪县中心广场`：没有检索到能支撑旅游规划的景点级资料，保留会把普通县城广场当作目的地推荐。
4. `西昌卫星发射基地景区大理办事处`、`尼珠河大峡谷景区曲靖办事处`：精确检索只得到办事处/机构目录结果，名称本身明确不是可游览景点。
5. `demo-533300-05｜老姆登村`：同一城市已有 `B0H2L76OAR｜老姆登村景区` 真实 POI，删除合成重复行；另外 4 条 demo 记录有公开资料，迁移为内部核验 ID 而不是直接删除。

## 当前仍需后续处理的项目

### 1. 向量库缺口

当前数据库有 5207 条有简介的景点文档，景点向量库有 4826 条，差 381 条；检查结果为“数据库缺向量”，不是“向量库残留”。此前的本地同步脚本只复用已有 embedding，不调用嵌入服务，因此不会自动补齐缺口。云南当前有 14 条景点缺向量。若要做到数量完全一致，需要单独授权一次嵌入重建，不能用零向量或伪造向量填充。

### 2. 12 条普通公园/广场候选

清洗脚本仍标记大观公园、巫家坝中央公园、金碧广场、昆明瀑布公园、黑龙潭公园、大理篝火打跳广场、风车广场、丽江市红太阳广场、文山七花广场、七都广场、西门公园、芒市广场。它们不一定是错误数据，其中部分有政府或文旅公开信息，因此没有批量删除；后续应决定是否继续作为城市休闲目的地参与规划。

### 3. 19 组同景区/父子景点重叠

主要包括石林、世博园、官渡古镇、西山、丽江古城、玉龙雪山、束河、泸沽湖、大理古城、崇圣寺三塔、南诏风情岛、蝴蝶泉、普者黑、热带植物园、告庄西双景、恐龙谷、老姆登村和虎跳峡等短名称与官方长名称记录。当前表没有 `parent_poi_id` 字段，本轮只输出复核清单，没有擅自合并或添加字段。
