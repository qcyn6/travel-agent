## 清洗范围

- 数据范围：`云南省`下的 335 条景点记录。

- 外部服务约束：本次未调用高德 API、地图 POI API 或地理编码服务；没有消耗高德额度。

## 保留人工复核的项目

### 1. 两条明显的非景点 POI

- `4412｜西昌卫星发射基地景区大理办事处`
- `4435｜尼珠河大峡谷景区曲靖办事处`

两条记录的名称明确属于办事处，不属于可游览景点。由于当前表已移除 `is_active` 等生命周期字段，本轮没有直接删除；确认后应连同向量索引中的对应文档一起清理。

### 2. 13 条普通城市公园/广场候选

大观公园、巫家坝中央公园、金碧广场、昆明瀑布公园、黑龙潭公园、大理篝火打跳广场、风车广场、丽江市红太阳广场、文山七花广场、七都广场、西门公园、芒市广场、兰坪县中心广场。

这些记录不一定是错误数据：部分可能是当地真实休闲目的地。因此仅标记为复核候选，没有批量删除。

### 3. 21 组同景区/父子景点重叠

主要包括石林、世博园、官渡古镇、西山、丽江古城、玉龙雪山、束河、泸沽湖、大理古城、崇圣寺三塔、南诏风情岛、蝴蝶泉、普者黑、热带植物园、告庄西双景、恐龙谷、老姆登村、虎跳峡等的短名称与官方长名称记录。

当前表没有 `parent_poi_id` 字段，不能在不改变模型的情况下表达父子关系；本轮只输出清单，没有擅自合并或删除。

## 公开核验依据

简介和分类核验优先参考云南省文化和旅游公开信息、文化和旅游部 5A 景区公告、景区主管部门及科研机构页面，例如：[云南省 5A 景区公开信息](https://culture.yunnan.cn/system/2023/11/16/032835898.shtml)、[文化和旅游部 5A 景区公告](https://app.www.gov.cn/govdata/gov/202402/11/512030/article.html)、[中国科学院西双版纳热带植物园](https://xtbg.cas.cn/2022/ykfw/ryxz/)、[腾冲市政府和顺古镇信息](https://www.tengchong.gov.cn/info/16031/5370103.htm)、[瑞丽市姐告边境贸易区信息](https://www.rl.gov.cn/Web/_F0_0_5PTXSPRBBC92922D7B764675A2.htm)。
