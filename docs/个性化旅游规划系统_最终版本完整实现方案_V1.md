# 7. 阶段 1：Route Tool

## 7.1 目标

给已经生成的旅游方案补充真实路线数据。

Route Tool 只负责：

```text
获取真实路线数据
```

不负责：

```text
判断路线是否合理
```

合理性由 Evaluator 判断。

## 7.2 RouteSegment

```python
from pydantic import BaseModel


class RouteSegment(BaseModel):
    origin_name: str
    destination_name: str

    origin_longitude: float | None = None
    origin_latitude: float | None = None

    destination_longitude: float | None = None
    destination_latitude: float | None = None

    distance_m: int | None = None
    duration_min: int | None = None

    mode: str = "driving"

    source: str
```

## 7.3 路线调用

例如：

```text
Day 1

西湖
↓
灵隐寺
↓
西溪湿地
```

程序生成：

```text
西湖 → 灵隐寺
灵隐寺 → 西溪湿地
```

并调用高德 Route API。

## 7.4 建议函数

```python
async def get_route(
    origin,
    destination,
    mode="driving",
) -> RouteSegment:
    ...
```

批量：

```python
async def enrich_day_routes(
    day_plan,
) -> list[RouteSegment]:
    ...
```

## 7.5 失败降级

```text
高德成功
→ source = amap

高德失败
↓
重试一次
↓
仍失败
↓
Haversine fallback
↓
source = fallback
```

fallback 只能表示估算，不冒充真实路径规划。

## 7.6 验收

输入：

```text
西湖
灵隐寺
西溪湿地
```

输出：

```text
相邻景点路线数据
+
每段距离
+
每段预计耗时
```

```python
class EvaluationIssue(BaseModel):

class EvaluationResult(BaseModel):
```

## 12.1 目标

## 12.2 计算

```python
total_minutes = (
    visit_minutes
    + route_minutes
    + meal_minutes
```

例如：



# 17. Evaluator 总节点

```python
async def evaluate_plan(
    plan: TravelPlan,
    requirement: TravelRequirement,
) -> EvaluationResult:

    issues = []

    issues += evaluate_schedule(plan)
    issues += evaluate_routes(plan)
    issues += evaluate_weather(plan)
    issues += evaluate_opening_hours(plan)

    preference_issues = await evaluate_preferences(
        plan=plan,
        requirement=requirement,
    )

    issues += preference_issues

    hard_issues = [
        issue
        for issue in issues
        if issue.severity == "high"
    ]

    return EvaluationResult(
        passed=len(hard_issues) == 0,
        issues=issues,
        replan_required=len(hard_issues) > 0,
    )
```

## 24.6 Redis 不可用


## 24.7 LLM 失败

```text
timeout
↓
retry
↓
返回清晰错误
```

原则：

> 单个外部服务失败不能让整个旅游规划系统直接崩溃。
