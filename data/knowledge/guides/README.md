# 普通模式旅游主题知识库

## 用途

本目录保存需要项目统一表达、后续可被 RAG 检索的旅游主题文档。

省份、城市、景点的基础介绍目前直接交给大模型回答，不在这里重复维护。路线、天气、交通耗时、开放状态和价格等实时信息也不写入这里，而是交给高德、和风天气等工具。

## 文档格式

每篇文档只解决一个主题，正文建议包含：

- 适用范围
- 关键词
- 核心建议
- 不适合由本文判断的内容
- 资料边界

文档内容以稳定、通用、可解释的建议为主；涉及医疗、天气预警、道路管制和政策变化时，只提供提醒，不替代专业意见或实时查询。
